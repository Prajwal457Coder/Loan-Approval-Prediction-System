# 🏦 Loan Approval Prediction System

A Machine Learning-based web application that predicts whether a loan application is likely to be approved or rejected based on applicant details. The project uses data preprocessing, feature engineering, feature selection, and classification algorithms to provide accurate predictions.

---

## 📌 Project Overview

The Loan Approval Prediction System helps financial institutions or bank to automate the loan approval process by analyzing applicant information and predicting loan eligibility.

---

## 🚀 Features

- 📊 Exploratory Data Analysis (EDA)
- 🛠 Data Preprocessing and Cleaning
- 🔄 Feature Engineering
- 🔢 One-Hot Encoding for Categorical Variables
- 🎯 Feature Selection
- 🤖 Machine Learning Model Training
- 📈 Performance Evaluation
- 🌐 Interactive User Interface using Streamlit
- ⚡ Real-time Loan Approval Prediction

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/Loan_Approval_Prediction.git
```

Move to the project directory:

```bash
cd Loan_Approval_Prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```
